`print` は値を画面に表示する関数です。
Flutterのプログラムでも、動作を確認するときによく使います。

## さまざまな値を表示する

`print` には文字列だけでなく、数値や計算式も渡せます。

```dart
void main() {
  print('こんにちは');
  print(10);
  print(3.14);
  print(10 - 2);
  print(10 + 2);
}
```

```text
こんにちは
10
3.14
8
12
```

`print` は表示のたびに最後に改行します。
空行を表示したいときは、空の文字列を渡します。
`print()` のように何も渡さないとエラーになります。

```dart
void main() {
  print('1行目');
  print('');
  print('3行目');
}
```

## 改行とエスケープシーケンス

文字列の中の `\n` は改行を表します。
バックスラッシュで始まるこのような特別な書き方を、エスケープシーケンスと呼びます。
macOSの日本語キーボードでは、`option` を押しながら `¥` キーを押すとバックスラッシュを入力できます。

```dart
void main() {
  print('AAA\nBBB');
}
```

```text
AAA
BBB
```

よく使うエスケープシーケンスは次のとおりです。

| 書き方 | 意味 |
| --- | --- |
| `\n` | 改行 |
| `\t` | タブ |
| `\'` | シングルクォーテーション |
| `\"` | ダブルクォーテーション |
| `\\` | バックスラッシュ |
| `\$` | ドル記号 |

文字列を囲むために使っているクォーテーションをそのまま書くと、そこで文字列が終わったと解釈されます。
バックスラッシュを前に置くと、ただの文字として扱われます。

```dart
void main() {
  print('She said "Hello"');
  print('It\'s fine');
  print('C:\\Users');
  print('名前\t年齢\t住所');
}
```

```text
She said "Hello"
It's fine
C:\Users
名前	年齢	住所
```

## 文字列の連結と埋め込み

`+` を使うと文字列を連結できます。

```dart
void main() {
  print('AAA' + 'BBB' + 'CCC');
}
```

文字列の中に変数の値を埋め込むこともできます。
これを文字列補間（インターポレーション）と呼びます。
`$変数名` と書くと、そこに変数の値が入ります。
`${ }` を使えば、計算式も埋め込めます。
変数は第8章で詳しく学びます。

```dart
void main() {
  int age = 30;
  print('私の年齢は$age歳です');

  int a = 10;
  int b = 5;
  print('$a + $b = ${a + b}');
}
```

```text
私の年齢は30歳です
10 + 5 = 15
```

## printでデバッグする

プログラムが思いどおりに動かないとき、原因の多くは変数の値が想定と違うことにあります。
処理の途中に `print` を入れて今の値を確かめると、どこで食い違っているかを絞り込めます。
エディタのデバッグ機能もありますが、小さな問題なら `print` で十分なことも多くあります。

## プログラムの実行順序

プログラムは、基本的に上から下へ1行ずつ実行されます。

```dart
void main() {
  print('1番目');
  print('2番目');
  print('3番目');
}
```

順序を間違えると、正しい結果が得られなかったり、エラーになったりします。
たとえば税込価格の計算では、価格と税率を決めてから計算する必要があります。

```dart
void main() {
  // 先に値を用意する
  int price = 1000;
  double taxRate = 0.1;

  // 用意した値を使って計算する
  double total = price * (1 + taxRate);
  print(total);
}
```

計算の行を `price` の宣言より上に移すと、まだ存在しない変数を使うことになりエラーになります。

なお、上から順に実行するこの動きとは別に、完了を待たずに次へ進む非同期処理という書き方もあります。
非同期処理は第43章で扱います。
