40人分の成績を処理するとき、同じコードを40回書くのは大変です。
同じ処理を繰り返す構文を使えば、短く書けます。

## for文

`for` の括弧には、セミコロンで区切って3つの要素を書きます。

```dart
void main() {
  for (int i = 0; i < 5; i++) {
    print('Hello');
  }
}
```

1. 初期化（`int i = 0`）：繰り返しの最初に一度だけ実行します。
2. 条件（`i < 5`）：毎回の処理の前に調べ、`true` の間は繰り返します。
3. 更新（`i++`）：毎回の処理の後に実行します。

`i` が0、1、2、3、4の間は処理を実行し、5になると条件が `false` になって終わるので、5回繰り返します。
更新を忘れると `i` が変わらず、条件が `true` のままになるので処理が永久に終わりません。
これを無限ループと呼びます。

変数 `i` はブロックの中で使えます。

```dart
void main() {
  // 1から10まで表示する
  for (int i = 1; i <= 10; i++) {
    print(i);
  }

  // 2ずつ増やす（0, 2, 4）
  for (int i = 0; i < 5; i += 2) {
    print(i);
  }

  // カウントダウンする
  for (int i = 3; i > 0; i--) {
    print(i);
  }
  print('発射');
}
```

繰り返す回数は `<` と `<=` のどちらを使うかで変わります。
1回ずれる間違いがよく起きるので、条件の境界の値には注意してください。

## 二重ループ

`for` の中に `for` を書くと、組み合わせを順に処理できます。
次のコードは掛け算の表を表示します。

```dart
void main() {
  for (int i = 1; i <= 3; i++) {
    String line = '';
    for (int j = 1; j <= 3; j++) {
      line += '${i * j} ';
    }
    print(line);
  }
}
```

```text
1 2 3 
2 4 6 
3 6 9 
```

`i` が1の間に `j` が1から3まで動き、次に `i` が2になって、また `j` が1から3まで動きます。
内側の処理は外側の回数と内側の回数を掛けた数だけ実行されるので、それぞれを100回にすると1万回実行されます。
ループを重ねると処理が急に重くなることを覚えておいてください。

## while文

`while` は、条件が `true` の間ずっとブロックを繰り返します。

```dart
void main() {
  int count = 0;

  while (count < 5) {
    print(count);
    count++;
  }

  print('終了');
}
```

`for` と違い、更新の処理は自分でブロックの中に書きます。
書き忘れると無限ループになります。

`while` は、繰り返す回数が事前にわからないときに向いています。
次のコードは、サイコロを振って6が出るまで繰り返します。

```dart
import 'dart:math';

void main() {
  Random random = Random();
  int dice = 0;

  while (dice != 6) {
    dice = random.nextInt(6) + 1;
    print('サイコロの目: $dice');
  }

  print('6が出ました');
}
```

`random.nextInt(6)` は0から5までの整数をランダムに返します。
1を足すことで1から6の値にしています。
1行目の `import` は、乱数の機能を読み込むための記述です。

## do-while文

`while` は最初の条件が `false` なら一度も実行されません。
少なくとも1回は実行したいときは `do-while` を使います。
条件を調べるのがブロックの後になります。

```dart
void main() {
  int number = 10;

  while (number < 5) {
    print('whileの中: $number');
  }

  do {
    print('doの中: $number');
  } while (number < 5);
}
```

```text
doの中: 10
```

## breakとcontinue

ループの途中で流れを変える命令が2つあります。
どちらも `for` と `while` の両方で使えます。

- `break`：ループをその場で終了します。
- `continue`：残りの処理を飛ばして、次の繰り返しへ進みます。

```dart
void main() {
  int number = 0;

  while (true) {
    number++;

    if (number % 2 == 0) {
      continue; // 偶数のときは下の処理を飛ばす
    }

    print(number);

    if (number >= 9) {
      break; // 9以上でループを抜ける
    }
  }
}
```

```text
1
3
5
7
9
```

`while (true)` は、`break` がなければ無限ループになります。
ループを抜ける条件に確実に到達するかどうかを確認してください。

DartPadでは、無限ループに陥るとブラウザのタブが固まることがあります。
その場合はタブを閉じて開き直します。
