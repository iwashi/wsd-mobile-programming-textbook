プログラムは上から下へ実行されますが、「雨が降っていたら傘を持つ」のように、条件によって処理を変えたい場面があります。
これを条件分岐と呼びます。

## if文

`if` の括弧に条件を書くと、条件が `true` のときだけ波括弧の中を実行します。

```dart
void main() {
  int age = 20;

  if (age >= 18) {
    print('あなたは成人です');
  }

  print('プログラムを終了します');
}
```

```text
あなたは成人です
プログラムを終了します
```

`age` を10に変えると、条件が `false` になり `if` の中は実行されません。
`プログラムを終了します` だけが表示されます。

## if-else文

`else` を続けると、条件が `false` のときの処理も書けます。
2つのうちどちらか一方だけが実行されます。

```dart
void main() {
  int age = 16;

  if (age >= 18) {
    print('あなたは成人です');
  } else {
    print('あなたは未成年です');
  }
}
```

```text
あなたは未成年です
```

## else if文

3つ以上に分けたいときは `else if` を使います。
上から順に条件を調べ、最初に `true` になったブロックだけを実行します。
どれにも当てはまらなければ、最後の `else` を実行します。

```dart
void main() {
  int score = 85;

  if (score >= 90) {
    print('評価A');
  } else if (score >= 80) {
    print('評価B');
  } else if (score >= 70) {
    print('評価C');
  } else if (score >= 60) {
    print('評価D');
  } else {
    print('不合格');
  }
}
```

```text
評価B
```

条件を書く順序には注意が必要です。
次のコードでは `score` が95でも `合格` と表示されます。
最初の `score >= 60` が先に成り立つので、2つ目の条件は調べられないからです。

```dart
void main() {
  int score = 95;

  if (score >= 60) {
    print('合格');
  } else if (score >= 90) {
    print('優秀');
  }
}
```

## ネストした条件分岐

`if` の中に `if` を書くこともできます。
このように入れ子にすることをネストと呼びます。

```dart
void main() {
  int age = 20;
  bool hasLicense = false;

  if (age >= 18) {
    print('年齢の条件を満たしています');
    if (hasLicense) {
      print('運転できます');
    } else {
      print('運転免許を取得してください');
    }
  } else {
    print('18歳になってから免許を取得できます');
  }
}
```

```text
年齢の条件を満たしています
運転免許を取得してください
```

ネストが深くなるとコードは読みにくくなります。
その場合は、第17章で学ぶ関数に処理を分けることを検討してください。

## 条件を組み合わせる

第10章で学んだ論理演算子を使うと、複数の条件を1つの `if` にまとめられます。

```dart
void main() {
  int age = 25;
  bool isStudent = false;
  String day = '土曜日';

  if (age >= 18 && age < 65) {
    print('通常料金の年齢です');
  }

  if (day == '土曜日' || day == '日曜日') {
    print('週末です');
  }

  if (!isStudent) {
    print('学割は使えません');
  }
}
```

論理演算子は `!`、`&&`、`||` の順に優先されます。
`&&` と `||` の関係は、掛け算と足し算の関係と同じと考えると覚えやすいでしょう。
複雑な条件では、括弧を付けて意図を明確にしてください。
