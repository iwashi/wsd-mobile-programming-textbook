FlutterアプリはDartという言語で書きます。
第2部と第3部では、Flutterを書くために必要なDartの文法を学びます。

## DartPadの使い方

Dartの学習には、ブラウザ上でDartを実行できる [DartPad](https://dartpad.dev/) を使います。
インストールは不要です。

画面の左側にコードを書き、`Run` ボタンを押すと右側に実行結果が表示されます。
エラーがあると、下側にメッセージが表示されます。
ネットワーク通信やキーボードからの入力など一部の機能は動きませんが、基本文法の学習には十分です。

コードは本書からコピーするだけでなく、全てとは言いませんが、ぜひ自分の手で入力してください。
脳内で仮説を立てた上で、数値を変えると結果がどう変わるかを試すと、理解が深まります。
プログラムにエラーはつきものなので、恐れずに試しましょう。

## Hello World

プログラミング言語を学ぶときは、画面に「Hello, World!」と表示するプログラムから始めるのが伝統です。

```dart
void main() {
  print('Hello, World!');
}
```

```text
Hello, World!
```

`main` は特別な関数で、Dartのプログラムはここから始まります。
プログラムの開始地点をエントリーポイントと呼びます。
`void` は「結果の値を返さない」という意味です。
`print` は画面に値を表示する関数です。
関数については第18章で詳しく説明するので、今はこの形を決まり文句として覚えてください。

文字列は、必ずシングルクォーテーションかダブルクォーテーションで囲みます。
どちらを使っても同じですが、始まりと終わりは揃えてください。

```dart
void main() {
  print('シングルクォーテーションの文字列');
  print("ダブルクォーテーションの文字列");
}
```

## プログラムの構造

もう少し長いプログラムで、構造を表す用語を確認します。

```dart
void main() {
  // 計算する
  int sum = 1 + 2;

  // 表示する
  print(sum);
}
```

- 文（ステートメント）：`print(sum);` のような1つの命令です。文の終わりにはセミコロンを書きます。
- ブロック：`{` と `}` で囲まれたひとまとまりです。第19章で学ぶ変数の有効範囲にも関わります。
- インデント：ブロックの中身を右にずらす字下げです。

DartではPythonと違い、インデントがなくてもプログラムは動きます。
インデントをそろえると、どの文がどのブロックに含まれるかを読み取りやすくなります。
意味の区切りに空行を入れるのも、読みやすくするのに有効です。

## コメント

`//` から行末まではコメントになり、実行時には無視されます。
プログラムを読む人のためのメモとして使います。
複数行のコメントは `/*` と `*/` で囲みます。
公式ドキュメントのように、関数やクラスの説明を書くための `///` というコメントもあります。

```dart
void main() {
  // この行は実行されません
  print('実行されます'); // ここも行末までコメントです

  /*
  複数行に
  わたるコメントです
  */
}
```

コメントには、コードを読めばわかることではなく、コードだけではわからないことを書きます。

```dart
void main() {
  // よくないコメント：コードの内容を繰り返しているだけ
  // 価格に1.1を掛ける
  double price = 1000 * 1.1;

  // よいコメント：なぜそうするのかを書いている
  // 表示価格は税込にする決まりなので、消費税10%を加える
  double displayPrice = 1000 * 1.1;

  // TODO: 軽減税率に対応する
  print(price);
  print(displayPrice);
}
```

計算の目的、特殊な値の意味、変更するときの注意点、これからやる作業のメモ（`TODO`）などを残しておくと役に立ちます。
コードと食い違ったコメントや、説明が長すぎるコメントはかえって読む人を混乱させます。
