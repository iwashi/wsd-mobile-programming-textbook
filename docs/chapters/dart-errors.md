プログラムを書いていると、エラーは必ず出ます。
エラーメッセージは原因を伝えるために表示されているので、まず落ち着いて読みます。

## エラーが出たら場所と内容を読む

次のコードは、`print` の文の最後にセミコロンがありません。

```dart
void main() {
  print('Hello, World!')
}
```

DartPadの下側に、次のようなメッセージが表示されます。

```text
line 2 • column 24
Expected to find ';'.
```

`line 2` は2行目、`column 24` はその行の24文字目を指します。
メッセージの内容は「`;` があるはずなのに見つからない」です。
このようにメッセージには、問題の場所と内容が書かれています。
英語でも、短い文を読むつもりで確認すれば原因がわかることが多くあります。

## よくあるエラー

### 括弧の対応が取れていない

丸括弧や波括弧は、開いたら必ず閉じます。
`main` の `{` に対応する `}` がなかったり、`print(` の `)` が抜けていたりするとエラーになります。

### 定義されていない名前を使っている

宣言していない変数を使うと、`Undefined name` というエラーになります。
よくある原因は綴りの間違いです。

```dart
void main() {
  String name = '太郎';
  print(nmae); // nameの綴りを間違えている
}
```

### 型が合わない

変数には入れられる値の種類（型）が決まっています。
整数を入れる `int` 型の変数に文字列を入れようとするとエラーになります。

```dart
void main() {
  int number = 'Hello';
  print(number);
}
```

メッセージには、`String` 型の値は `int` 型の変数に代入できないという内容が表示されます。
`'Hello'` を `10` のような整数に変えれば解消します。

## コンパイルエラーと実行時エラー

Dartは、プログラムを実行する前に、機械が実行できる形へ変換します。
これをコンパイルと呼びます。
ここまでのエラーはこの段階で見つかるもので、コンパイルエラーと呼ばれます。

一方で、実行してみるまでわからないエラーもあります。
これを実行時エラー（ランタイムエラー）と呼びます。
たとえば次のコードは問題なく実行を始められますが、`~/`（整数の割り算）で0で割ろうとした時点で停止します。

```dart
void main() {
  int a = 10;
  int b = 0;
  print(a ~/ b);
}
```

たとえば `b` の値がインターネットから取得したものなら、実行するまで0かどうかはわかりません。

ちなみに `/` を使った通常の割り算では、0で割ってもエラーにならず、結果は `Infinity`（無限大）になります。
言語によって動きが異なる部分です。

## エラーを解決する手順

1. 落ち着いてメッセージを読む
2. コンパイルエラーか実行時エラーかを確認する
3. 表示された行とその周辺を確認する
4. 修正して再度実行する

メッセージの行そのものではなく、その手前に原因があることもあります。
表示された行を直しても解決しないときは、範囲を広げて確認してください。

## エラーを減らす書き方

- 少しずつ書いて、こまめに実行する。一度に長いコードを書いて1回で動かせる人はほとんどいません。
- `Format` ボタンで字下げを整える。構造が見えやすくなり、括弧の間違いにも気付きやすくなります。
- 意図をコメントに残す。数日後に読み返すときの助けになります。
