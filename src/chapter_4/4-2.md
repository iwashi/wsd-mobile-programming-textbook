# 文字列と数値の変換

前述した intParse() に加えて、 toString() も使うことがありますので、覚えておきましょう。

```dart
void main() {
  String numText = '123';
  int number = int.parse(numText); // 文字列を整数に変換
  print('文字列「$numText」を数値に変換: $number');
  
  String piText = '3.14';
  double pi = double.parse(piText); // 文字列を小数に変換
  print('文字列「$piText」を数値に変換: $pi');
}
```

変換すれば、計算に使えるようになります：

```dart
void main() {
  String priceText = '150';
  int price = int.parse(priceText);
  
  print(priceText + priceText);  // 150150（文字列の連結になってしまう）
  print(price + price);          // 300（正しく計算できる）
}
```

### 変換できない文字列に注意

数値として解釈できない文字列を `int.parse()` に渡すと、実行時にエラー（FormatException）が発生してプログラムが停止します：

```dart
void main() {
  int number = int.parse('abc'); // 実行時エラー！
  print(number);
}
```

```
Uncaught Error: FormatException: abc
```

「ユーザーが入力した文字列を数値に変換する」ような場面では、数値以外が入力される可能性を常に考える必要があります。こうしたエラーへの対処方法は、第13章「エラーへの対処」で詳しく学びます。

## 数値を文字列に変換する

逆に、数値を文字列に変換するには `toString()` を使います：

```dart
void main() {
  int value = 456;
  String valueText = value.toString(); // 数値を文字列に変換
  print('数値$valueを文字列に変換: 「$valueText」');
  
  double height = 170.5;
  String heightText = height.toString();
  print('身長: ' + heightText + 'cm'); // 文字列として連結できる
}
```

## 数値どうしの変換（intとdouble）

`int` と `double` の間で変換したいときは、`toDouble()` と `toInt()` を使います：

```dart
void main() {
  int count = 5;
  double countDouble = count.toDouble();
  print(countDouble);  // 5.0
  
  double average = 79.8;
  int averageInt = average.toInt();  // 小数部分は切り捨てられる
  print(averageInt);   // 79
}
```

`toInt()` は四捨五入ではなく**切り捨て**である点に注意してください。四捨五入したい場合は `round()` を使います：

```dart
void main() {
  double score = 79.8;
  print(score.toInt());   // 79（切り捨て）
  print(score.round());   // 80（四捨五入）
}
```
