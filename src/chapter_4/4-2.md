# 文字列と数値の変換

「文字列の `'123'`」と「数値の `123`」は、見た目は似ていますが、コンピュータにとってはまったく別のデータです。文字列のままでは計算ができないため、両者を変換する方法を知っておく必要があります。

## 文字列を数値に変換する

文字列を数値に変換するには、`int.parse()`（整数）や `double.parse()`（小数）を使います：

```dart
void main() {
  String numText = '123';
  int number = int.parse(numText); // 文字列を整数に変換
  print('文字列「$numText」を数値に変換: $number');
  
  String piText = '3.14';
  double pi = double.parse(piText); // 文字列を小数に変換
  print('文字列「$piText」を数値に変換: $pi');
}
```

変換すれば、計算に使えるようになります：

```dart
void main() {
  String priceText = '150';
  int price = int.parse(priceText);
  
  print(priceText + priceText);  // 150150（文字列の連結になってしまう）
  print(price + price);          // 300（正しく計算できる）
}
```

### 変換できない文字列に注意

数値として解釈できない文字列を `int.parse()` に渡すと、実行時にエラー（FormatException）が発生してプログラムが停止します：

```dart
void main() {
  int number = int.parse('abc'); // 実行時エラー！
  print(number);
}
```

```
Uncaught Error: FormatException: abc
```

「ユーザーが入力した文字列を数値に変換する」ような場面では、数値以外が入力される可能性を常に考える必要があります。こうしたエラーへの対処方法は、第13章「エラーへの対処」で詳しく学びます。

## 数値を文字列に変換する

逆に、数値を文字列に変換するには `toString()` を使います：

```dart
void main() {
  int value = 456;
  String valueText = value.toString(); // 数値を文字列に変換
  print('数値$valueを文字列に変換: 「$valueText」');
  
  double height = 170.5;
  String heightText = height.toString();
  print('身長: ' + heightText + 'cm'); // 文字列として連結できる
}
```

## 数値どうしの変換（intとdouble）

`int` と `double` の間で変換したいときは、`toDouble()` と `toInt()` を使います：

```dart
void main() {
  int count = 5;
  double countDouble = count.toDouble();
  print(countDouble);  // 5.0
  
  double average = 79.8;
  int averageInt = average.toInt();  // 小数部分は切り捨てられる
  print(averageInt);   // 79
}
```

`toInt()` は四捨五入ではなく**切り捨て**である点に注意してください。四捨五入したい場合は `round()` を使います：

```dart
void main() {
  double score = 79.8;
  print(score.toInt());   // 79（切り捨て）
  print(score.round());   // 80（四捨五入）
}
```

## 実用例：合計金額の計算

文字列で受け取った価格データを数値に変換して計算する例です：

```dart
void main() {
  // 例えば、ファイルや画面入力から文字列として受け取ったデータ
  String priceText1 = '1200';
  String priceText2 = '850';
  
  // 数値に変換してから計算する
  int price1 = int.parse(priceText1);
  int price2 = int.parse(priceText2);
  int total = price1 + price2;
  
  print('合計金額: $total円'); // 合計金額: 2050円
}
```

## 練習問題

**問題1**：次のプログラムの実行結果を予想してください。

```dart
void main() {
  String a = '10';
  String b = '20';
  
  print(a + b);
  print(int.parse(a) + int.parse(b));
}
```

<details>
<summary>解答例</summary>

```
1020
30
```

文字列どうしの `+` は連結（`'10'` と `'20'` をつなげて `'1020'`）、数値に変換してからの `+` は足し算（30）になります。

</details>

**問題2**：`double` 型の変数 `temperature = 36.78;` を、「体温は37度です」のように四捨五入した整数で表示するプログラムを書いてください。

<details>
<summary>解答例</summary>

```dart
void main() {
  double temperature = 36.78;
  int rounded = temperature.round();
  print('体温は$rounded度です');  // 体温は37度です
}
```

`toInt()` を使うと切り捨てで36度になってしまいます。用途に応じて使い分けましょう。

</details>

文字列と数値の変換を正しく使い分けることで、ユーザーに分かりやすいメッセージを表示したり、受け取ったデータを計算に使ったりできます。次は変数の値を変更する方法について学んでいきましょう。
