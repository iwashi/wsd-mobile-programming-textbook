# 演算の優先順位

数学と同様に、プログラミングでも計算には決まった順番があります。演算子の優先順位を理解することで、期待通りの計算結果を得ることができます。

## 基本的な演算の優先順位

数学の計算と同じルールが適用されます：

```dart
void main() {
  // 掛け算と割り算は足し算と引き算より先に実行される
  int result1 = 2 + 3 * 4;
  print('2 + 3 * 4 = $result1'); // 2 + 3 * 4 = 14 (3*4が先に計算される)
  
  double result2 = 10 - 6 / 2;
  print('10 - 6 / 2 = $result2'); // 10 - 6 / 2 = 7 (6/2が先に計算される)
}
```

## 括弧を使った優先順位の変更

括弧を使うことで、計算の順序を明示的に指定できます：

```dart
void main() {
  // 括弧なし
  int result1 = 2 + 3 * 4;
  print('2 + 3 * 4 = $result1'); // 14
  
  // 括弧あり
  int result2 = (2 + 3) * 4;
  print('(2 + 3) * 4 = $result2'); // 20
  
  // より複雑な例
  double result3 = (10 + 5) / (3 * 2);
  print('(10 + 5) / (3 * 2) = $result3'); // 2.5
}
```

## 実践的なアドバイス

### 1. 読みやすさを優先する
```dart
void main() {
  int a = 10, b = 5, c = 2;
  
  // 技術的には正しいが読みにくい
  int complex = a + b * c - a ~/ b + c % 2;
  
  // 括弧を使って意図を明確にする
  int clear = a + (b * c) - (a ~/ b) + (c % 2);
  
  print('複雑: $complex, 明確: $clear');  // 複雑: 18, 明確: 18
}
```

### 2. 段階的な計算
```dart
void main() {
  // 複雑な計算は段階的に分ける
  double basePrice = 1200;
  double discountRate = 0.15;
  double taxRate = 0.08;
  
  double discountAmount = basePrice * discountRate;
  double discountedPrice = basePrice - discountAmount;
  double tax = discountedPrice * taxRate;
  double finalPrice = discountedPrice + tax;
  
  print('元の価格: ${basePrice}円');
  print('割引額: ${discountAmount}円');
  print('割引後価格: ${discountedPrice}円');
  print('税額: ${tax}円');
  print('最終価格: ${finalPrice}円');
}
```

## 練習問題

**問題1**：次のプログラムの実行結果を予想してください。

```dart
void main() {
  print(2 + 3 * 4);
  print((2 + 3) * 4);
  print(10 - 4 - 3);
}
```

<details>
<summary>解答例</summary>

```
14
20
3
```

- `2 + 3 * 4` は掛け算が先なので 2 + 12 = 14
- `(2 + 3) * 4` は括弧が最優先なので 5 × 4 = 20
- `10 - 4 - 3` は同じ優先順位の演算子は左から計算するので 6 - 3 = 3

</details>

**問題2**：3教科のテストの点数（80点、65点、92点）の平均点を計算するプログラムを書いてください。括弧の使い方に注意しましょう。

<details>
<summary>解答例</summary>

```dart
void main() {
  int math = 80;
  int english = 65;
  int science = 92;
  
  double average = (math + english + science) / 3;
  print('平均点: $average');  // 平均点: 79.0
}
```

括弧がないと `math + english + science / 3` は「scienceだけを3で割ってから足す」ことになってしまいます。

</details>

演算の優先順位を理解することで、正確な計算結果を得ることができ、他の人が読みやすいコードを書くことができます。
