# クラスの定義

前の章で、オブジェクト指向プログラミングの考え方を学びました。今度は、実際にDartでオブジェクトを作るための「**クラス**」について学んでいきましょう。

## クラスとは何でしょうか？

クラスは、オブジェクトの「**設計図**」や「**型紙**」のようなものです。

### 身近な例で考えてみましょう

たい焼きを作ることを想像してください：

- **たい焼きの型**：これがクラス（設計図）
- **実際のたい焼き**：これがオブジェクト（実体）

一つの型（クラス）があれば、同じ形のたい焼き（オブジェクト）を何個でも作ることができますね！

```dart
// たい焼きのイメージ
たい焼きの型（クラス） → たい焼き1（オブジェクト）
                    → たい焼き2（オブジェクト）
                    → たい焼き3（オブジェクト）
```

## Dartでのクラスの基本形

Dartでクラスを定義する基本的な形は次のようになります：

```dart
class クラス名 {
  // ここにクラスの内容を書きます
}
```

### 実際に犬のクラスを作ってみましょう

```dart
class Dog {
  // まずは空のクラスを作成
}
```

おめでとうございます！これで最初のクラスができました。でも、まだ何も中身がありませんね。

## クラスに属性（フィールド）を追加する

犬には名前、年齢、品種などの情報が必要です。これらを**フィールド**と呼びます（本書では「フィールド」という呼び方で統一します）。

```dart
class Dog {
  // 犬の属性（フィールド）
  String name;    // 名前
  int age;        // 年齢
  String breed;   // 品種
}
```

### フィールドの説明

- `String name`：犬の名前を文字列で保存
- `int age`：犬の年齢を整数で保存  
- `String breed`：犬の品種を文字列で保存

> **注意**：実は、このコードをそのままDartPadに入力すると「フィールドに値が入っていない」というエラーになります。Dartでは、フィールドには必ず値を設定する必要があるためです。設定方法は2つあり、この節の後半で説明する「**初期値の設定**」と「**コンストラクタ**」です。まずはクラスの形に慣れましょう。

## より詳しいクラスの例

もう少し現実的な例を見てみましょう：

```dart
class Dog {
  // 基本情報
  String name;        // 名前
  int age;           // 年齢
  String breed;      // 品種
  String color;      // 毛色
  double weight;     // 体重（kg）
  bool isHealthy;    // 健康状態
}
```

### データ型の選択

各フィールドにはどのデータ型が適切か考えてみましょう：

- **String（文字列）**：名前、品種、毛色など
- **int（整数）**：年齢（通常は整数で表現）
- **double（小数）**：体重（小数点が必要）
- **bool（真偽値）**：健康状態（健康/不健康の2択）

## 別の例：学生クラス

犬以外の例も見てみましょう：

```dart
class Student {
  String name;        // 名前
  int grade;         // 学年
  int studentId;     // 学籍番号
  double gpa;        // 成績平均点
  bool isPresent;    // 出席しているかどうか
}
```

## クラス名の命名規則

Dartでは、クラス名には特別な命名規則があります：

### 1. パスカルケース（PascalCase）を使う

```dart
// ✅ 正しい例
class Dog { }
class Student { }
class BankAccount { }     // 複数の単語は最初を大文字に
class GameCharacter { }

// ❌ 間違った例
class dog { }             // 小文字で始まっている
class bank_account { }    // アンダースコアを使っている
class gamecharacter { }   // 2番目の単語が小文字
```

### 2. 意味のある名前をつける

```dart
// ✅ 良い例
class Car { }           // 車
class Book { }          // 本
class MusicPlayer { }   // 音楽プレーヤー

// ❌ 悪い例
class A { }             // 何を表すかわからない
class Thing { }         // 抽象的すぎる
class Data { }          // 何のデータかわからない
```

## 練習：自分でクラスを作ってみよう

本を表現するクラスを作ってみてください。本には次のような属性があります：

- タイトル（文字列）
- 著者（文字列）
- ページ数（整数）
- 価格（小数）
- 読み終わったかどうか（真偽値）

```dart
class Book {
  // ここに属性を書いてください
}
```

**答え**：

```dart
class Book {
  String title = "";       // タイトル
  String author = "";      // 著者
  int pages = 0;           // ページ数
  double price = 0.0;      // 価格
  bool isFinished = false; // 読み終わったかどうか
}
```

（フィールドに初期値を付けているのは、前述のとおりDartでは値の設定が必須だからです）


## 初期値の設定

フィールドには初期値を設定することもできます：

```dart
class Dog {
  String name = "名前未設定";     // デフォルトの名前
  int age = 0;                  // デフォルトの年齢
  String breed = "雑種";        // デフォルトの品種
  bool isHealthy = true;        // デフォルトで健康
}
```

## コンストラクタ：作るときに値を渡す

初期値の設定では、どのオブジェクトも同じ値で始まります。「オブジェクトを作るときに、それぞれ違う値を設定したい」場合は、**コンストラクタ**を使います：

```dart
class Dog {
  String name;
  int age;
  
  // コンストラクタ：オブジェクトを作るときに呼ばれる特別な関数
  Dog(this.name, this.age);
}

void main() {
  Dog dog1 = Dog('ポチ', 3);   // 名前と年齢を渡して作る
  Dog dog2 = Dog('ハチ', 5);   // 別の値で作れる
  
  print('${dog1.name}は${dog1.age}歳');  // ポチは3歳
  print('${dog2.name}は${dog2.age}歳');  // ハチは5歳
}
```

- コンストラクタは**クラス名と同じ名前**を付けます
- `this.name` は「受け取った値をフィールド `name` に入れる」という意味です
- コンストラクタで値を設定するので、フィールドに初期値を書かなくてもエラーになりません

ここでは「コンストラクタ＝オブジェクトを作るときに値を渡す仕組み」とだけ理解できれば十分です。より高度な使い方は第12章で詳しく学びます。

2. **基本的な構文**：`class クラス名 { }`
3. **フィールド**：オブジェクトが持つ属性（データ）
4. **命名規則**：パスカルケースで意味のある名前を
5. **データ型**：適切な型を選択する
